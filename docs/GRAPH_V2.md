# Workflow graph schema v2 (bounded initial slice)\n\n`version: 2` accepts optional `next` action identifiers for a single connected, acyclic, linear directed graph. Unknown targets, loops, forks, merges and disconnected actions are rejected; v1 remains unchanged. No conditional branching, expressions, retries, or credential features are claimed in this slice. These require separate semantics, validation, adversarial cases and live staging. This initial IR makes edge relationships explicit without pretending to support branching.\n
